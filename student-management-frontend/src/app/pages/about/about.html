About This Project

The Student Management System is a full-stack web application built with Angular and Spring Boot for managing students, departments, and student profiles.

Current Features

  • Secure login with JWT authentication
  • USER and ADMIN role-based access
  • View all students
  • Search students by name, course, or department
  • View individual student details
  • Add, edit, and delete students as an administrator
  • Assign students to departments
  • Create and view departments
  • View, create, and update student profiles
  • Form validation and user-friendly error handling
  • Responsive Angular Material interface

Technologies

Angular 22, TypeScript, Angular Material, RxJS, Spring Boot 4.1, Java 21, Spring Data JPA, Hibernate, Spring Security, JWT, Microsoft SQL Server, Maven, Vitest, and H2 for automated tests.

Security

The application uses stateless JWT authentication and role-based authorization. Administrator-only actions are protected by the Spring Boot backend, not only hidden in the frontend.

Project Purpose

This project was built as a practical full-stack development project covering frontend development, REST API design, relational databases, authentication, authorization, validation, testing, and frontend-backend integration.
